GET Send Likes 01
GET /api/likes?uid={uid}&server_name={server}&key={your_api_key}
Parameters
Name Type Required Description
uid string required Target user ID to send likes to
server_name string required Server region: IND, BR, US, SAC, NA, BD
key string required Your API key
Example Request
curl "http://localhost:5000/api/likes?uid=4119418341&server_name=IND&key=your_key"
